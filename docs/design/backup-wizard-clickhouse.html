Before the first native run
ClickHouse connects to the server's ingest endpoint (ingest.url) directly, not through the agent tunnel:
  • allow egress from the ClickHouse pods to that host and port, for example with a NetworkPolicy (docs/install.md);
  • ClickHouse must trust the endpoint's certificate: one from your PKI or a public CA, or else the Olympos CA in openSSL.client.caConfig.
Each run gets its own credential for its own backup only, revoked when the run ends. The backup data does not pass through the agent; the BACKUP statement, with the run's credential, does, in the cluster's transfer mode (in the clear in compressed mode).
